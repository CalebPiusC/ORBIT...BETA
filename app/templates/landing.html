How it works

From first question to reviewed change, in three moves.

ORBIT is built around one idea: the AI does the legwork, you keep the decisions. The approval gate isn’t a setting — it’s the product.

1

Describe it

Tell Orbit what you want in the home chat — Quick for fast answers, Deep when you want it to think harder. Hold-to-talk voice input is in testing.

2

Plan it together

Every project gets a workspace: a Main Agent that knows the goal, a task map you organize by stage, and specialists — Coding, Research, Debug, Review, Testing, Documentation — you assign where they fit.

3

Approve before it runs

When Orbit wants to run a tool — save a note, remember a fact, save today’s plan, pause reminders — the request waits on a card until you click Approve. Declines are recorded too. Approving proposed code changes comes with the Git integration.

What’s inside

A real workspace, not a chat box.

Everything below is live in the beta today, except what is labelled otherwise — because pretending otherwise is how products lose your trust.

Chat & Agent modes

Working today

One toggle switches between conversation and an agent that plans a task and works a checklist from your request. Drafting the code changes for your review is coming next.

Project workspaces

Working today

Each project has a map of tasks by stage, a detail view, and its own Main Agent thread with the project’s full context.

Agent specialists

Working today

Six specialties — Coding, Research, Debug, Review, Testing, Documentation — each with its own brief, assignable to any project.

The approval gate

Working today

Every tool call queues behind an explicit Approve, and every decision — including declines — is written to an audit log. Approving proposed code changes arrives with the Git integration.

Voice & reminders

Voice in testing

Reminders work today: daily-plan check-ins with quiet hours, and phone push if you want it. Hold-to-talk input and spoken replies are built and in testing — clips are processed locally and never stored.

Git providers & imports

Coming next

No Git provider is connected yet — GitHub included. The GitHub, GitLab, Bitbucket and file/ZIP entry points are visible in the app and visibly disabled until they are real.

The beta promise

Early, honest, and built with you.

ORBIT is in open beta. That means the core loop is real and daily-usable, the edges are clearly marked, and your feedback goes straight into what gets built next. Here’s exactly where things stand:

  • ✓Working daily: chat and agent modes, project workspaces, specialists and reminders — with a streaming reply that never leaves you guessing.
  • ◐In testing: hold-to-talk voice and spoken replies. Built, not yet proven on every machine — tell us when it fails.
  • ◐Visibly unfinished: connecting any Git provider — GitHub included — and importing from files. The entry points are there, disabled and labelled, never faked as working.
  • ✓Never unfinished: the approval gate. No tool call runs without your yes, on day one, forever.

Found a rough edge? Missing something you need? The beta runs on exactly that signal.
