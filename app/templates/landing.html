How it works

From first question to reviewed change, in three moves.

ORBIT is built around one idea: the AI does the legwork, you keep the decisions. The approval gate isn’t a setting — it’s the product.

1

Describe it

Tell Orbit what you want in the home chat — Quick for fast answers, Deep when you want it to think harder. Attach files, talk by voice, whatever works.

2

Plan it together

Every project gets a workspace: a Main Agent that knows the goal, a task map you organize by stage, and specialists — Coding, Research, Debug, Review, Testing, Documentation — you assign where they fit.

3

Approve, then it ships

Proposed changes stay in draft until you say yes. No commits, no pushes without your explicit approval — that’s a rule the code enforces, not a caption.

What’s inside

A real workspace, not a chat box.

Everything below is live in the beta today — and one thing that isn’t, marked as such, because pretending otherwise is how products lose your trust.

Chat & Agent modes

Working today

One toggle switches between conversation and an agent that plans a task, works a checklist, and drafts changes for your review.

Project workspaces

Working today

Each project has a map of tasks by stage, a detail view, and its own Main Agent thread with the project’s full context.

Agent specialists

Working today

Six specialties — Coding, Research, Debug, Review, Testing, Documentation — each with its own brief, assignable to any project.

The approval gate

Working today

Tool calls and proposed changes queue behind an explicit Approve. Every decision, including declines, is written to an audit log.

Voice & reminders

Working today

Hold-to-talk input and spoken replies, plus daily-plan check-ins with quiet hours. Voice clips are processed locally and never stored.

Git providers & imports

Partly here

GitHub is connected today. GitLab, Bitbucket and file/ZIP import entry points are visible in the app — visibly disabled until they’re real.

The beta promise

Early, honest, and built with you.

ORBIT is in open beta. That means the core loop is real and daily-usable, the edges are clearly marked, and your feedback goes straight into what gets built next. Here’s exactly where things stand:

  • ✓Working daily: chat and agent modes, project workspaces, specialists, voice, reminders — with a streaming reply that never leaves you guessing.
  • ◐Visibly unfinished: importing from GitLab/Bitbucket or files. The entry points are there — disabled and labelled, never faked as working.
  • ✓Never unfinished: the approval gate. No change is applied without your yes, on day one, forever.

Found a rough edge? Missing something you need? The beta runs on exactly that signal.
